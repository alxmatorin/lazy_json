# Индекс корня и пакетные правки: 10 корневых полей

В `KeysScenario` теперь ровно 10 корневых полей: `key3`, `meta`, `key5`, `filler1`, `key`, `filler2`, `mid`, `status`, `filler3`, `key1`. Основной объём находится во вложенных объектах и массивах. Пул содержит 16 разных документов около 500 КиБ; первый занимает 511 974 байта. Маленький список `$key1.key2` остаётся в самом конце.

Изменения библиотеки:

- `RootIndex` выделяет буферы при первом добавлении записи и декодирует экранированные имена один раз. До 16 записей сохраняется линейный поиск; выше включается `HashMap`. В этом стенде с 10 полями хеш-индекс не включается.
- `Edits.apply()` переиспользует подготовленное дерево путей и значения. Добавление правки сбрасывает подготовку. `applyTo(other)` позволяет применить пакет к другому документу с его собственным индексом. Обычный `apply(List<Edit>)` по-прежнему готовит пакет при каждом вызове.
- Вставки копируют фрагменты сразу в итоговый массив, без промежуточного массива размером со вставку.

## Измерения

Сравнение библиотеки из `37756c7` с текущими изменениями. **Обе версии используют новый одинаковый сценарий с 10 корневыми полями**, один и тот же `RootAndEditsBenchmark` и пул из 16 документов. Jackson-стратегия не запускалась и удалена из списка стратегий `LazyLoopMain`; Jackson используется вне измеряемого участка для подготовки и проверки данных.

macOS arm64, Temurin JDK 21.0.7, `-Xms512m -Xmx512m`. По три отдельных JVM на версию, порядок: до/после, после/до, до/после. На каждую операцию три окна прогрева по 200 мс и пять измерений по 200 мс. Таблица содержит медианы трёх медиан. Аллокации получены через `ThreadMXBean`; дробные байты отражают усреднение по документам разной длины.

`cold` создаёт новый `LazyJson` на каждую операцию. `cached` предварительно индексирует корень поиском отсутствующего ключа; эта подготовка не входит в измерение. `start` ищет `$key3.key4`, `tail` — `$key1.key2`, `root` — `$key1`. Для варианта `escaped` первые символы имён ключей заменены на Unicode escape-последовательности, структура и значения сохранены.

`batch/reused` повторно применяет заранее собранный билдер; `fresh` создаёт и заполняет его внутри измерения. Оба заменяют `$<key1.key2` и добавляют остальные поля внутрь `key1`. `large` заменяет `$<key1.key2` либо вставляет `$<key1.payload`: значение — JSON-строка из 500 000 символов, итоговый документ около 1 МБ.

Большая вставка занимает на 39% меньше времени и выделяет на 500 008 байт меньше памяти. Повторный пакет из 10 правок ускорился примерно на 6%; копирование исходных 500 КиБ всё ещё составляет основную работу. Обычный поиск хвоста, хинт и большие замены практически не изменились. У `cached-root` исходные прогоны разбросаны от 29.2 до 40.6 нс, поэтому результат 1.34× нельзя считать устойчивой оценкой выигрыша. Различия около 1–2% в остальных строках также не интерпретируются как изменение производительности.

Исходные результаты: [root-and-edits-results](root-and-edits-results/). Это локальный сравнительный стенд, а не оценка всех возможных документов и нагрузок.

## Проверка

109 тестов проходят. Новые проверки охватывают форму всех 16 документов, рост индекса и коллизии хешей, смешанный прямой и обратный обход, экранированные Unicode-ключи, сброс подготовленного пакета после добавления правки, применение к документу с другими смещениями и большие вставки вместе с заменами. Результат последней проверки полностью разбирается Jackson с `FAIL_ON_TRAILING_TOKENS`, сравниваются значения и неизменность исходного документа.

## Воспроизведение

Использовать JDK 21. Для текущей версии:

```sh
mvn test dependency:build-classpath -Dmdep.outputFile=target/benchmark-classpath.txt
BENCH_CP="target/test-classes:target/classes:$(cat target/benchmark-classpath.txt)"
java -Xms512m -Xmx512m -cp "$BENCH_CP" ru.sber.lazyjson.RootAndEditsBenchmark
```

Для исходной библиотеки, сохраняя **текущие** классы сценария и стенда:

```sh
mkdir -p target/root-before/classes
git archive 37756c7 src/main/java/ru/sber/lazyjson | tar -x -C target/root-before
rg --files target/root-before/src/main/java -g '*.java' > target/root-before/sources.txt
javac --release 21 -cp "$BENCH_CP" -d target/root-before/classes @target/root-before/sources.txt
java -Xms512m -Xmx512m -cp "target/root-before/classes:$BENCH_CP" ru.sber.lazyjson.RootAndEditsBenchmark
```

Повторить каждую команду `java` три раза, чередуя версии. Замеры запускаются последовательно.
